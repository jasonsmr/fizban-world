# Why this works

The earlier draft could describe *weird places* without showing *what happened to you*.

This build forces every encounter to behave like a functional game beat:

1. **Concrete trigger** ("you drop a pebble…")
2. **Observable anomaly** ("you hear it land before it falls")
3. **Mechanism framing** ("the place learns cause/effect and replays it wrong")
4. **Escalation rule** ("linger and it predicts your next sentence")
5. **Choice tradeoffs** (slow/paid/forced) with:
   - immediate outcome
   - visible cost
   - a small, capped worldstate proposal (≤2)

Mystery is preserved because we never explain *why* the mountain works this way—
we just make the impossible behavior **specific enough to imagine** and **costly enough to matter**.
